# System Enumeration

### 

| Command | What it does (one line) |
| --- | --- |
| `uname -a` | Displays full system information including kernel version, architecture, and OS details. |
| `hostname` | Shows the name of the current machine/system on the network. |
| `cat /etc/issue` | Displays the OS identification message shown before login (often shows Linux distribution info). |
| `cat /proc/version` | Shows detailed Linux kernel version information and compiler used to build it. |
| `lscpu` | Displays detailed information about the CPU architecture and processor specs. |
| `ps aux` | Lists all running processes on the system with details like user, PID, CPU, and memory usage. |
