# User Enumeration

| Command | What it does (one line) |
| --- | --- |
| `whoami` | Displays the username of the currently logged-in user. |
| `id` | Shows the current user's UID, GID, and group memberships. |
| `sudo -l` | Lists the commands the current user is allowed to run with sudo privileges. |
| `history` | Displays the list of previously executed shell commands. |
| `cat /etc/passwd` | Shows user account information such as usernames, UID, home directory, and shell. |
| `cat /etc/shadow` | Displays encrypted user password hashes and password policy info (usually requires root). |
| `cat /etc/group`  | Shows system groups and the users belonging to each group. |
